# Front-End Web Foundations (HTML5, Bootstrap 5, JavaScript & Jest)

Practical web development exercises and mini-projects covering semantic HTML5 structure, responsive Bootstrap 5 UI components, modern JavaScript (ES6+), object-oriented programming, and automated unit testing.

## 📂 Repository Structure

| Folder / File | Topic | Description |
| :--- | :--- | :--- |
| `html5-labs/` | **Semantic HTML5** | Progressive HTML5 markup exercises covering forms, tables, media, and document structure. |
| `bootstrap-labs/little-lemon-menu.html` | **Responsive UI (Bootstrap 5)** | Grid-based responsive menu layout styled with Bootstrap 5 utilities and components. |
| `js-algorithms/little-lemon-receipt-maker.js` | **JavaScript Data Processing** | Calculates item pricing, taxes, and formatted receipt outputs dynamically. |
| `js-algorithms/es6-inheritance.js` | **ES6 Classes & OOP** | Demonstrates class hierarchies, inheritance, and method overriding in JavaScript. |
| `js-unit-testing/addfive.js` & `addFive.test.js` | **Jest Unit Testing** | Implements a utility function and verifies behavior with Jest test assertions. |

## 🛠️ Tech Stack
* **Technologies:** HTML5, CSS3, Bootstrap 5, JavaScript (ES6+), Jest
